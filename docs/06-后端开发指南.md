# 后端开发指南

在 backend 使用 .venv/Scripts/python.exe，依赖见 requirements.txt。启动：.venv/Scripts/python.exe -m uvicorn app.main:app --reload --host 127.0.0.1 --port 8000。

main.py 初始化数据库及幂等自动确认；模型首次获取信息/推理时加载，替换权重后重启。写接口检查 Origin、Cookie 和角色，Pydantic 校验参数；人工框验证类别快照、边界和面积。

业务变更与审计处于事务中；媒体保存失败须清理文件；报告保持生成时快照。新记录保存权重指纹，旧记录缺失指纹不得回填当前模型。

queries.py 负责服务端全量筛选后分页，限制 limit、校验日期，员工日志先按用户隔离再筛选。

测试：.venv/Scripts/python.exe -m unittest discover -s tests -v。测试使用独立临时数据，不污染 backend/data。
