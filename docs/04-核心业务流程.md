# 核心业务流程

1. 建批次、登记钢板，选择关联；也可先试检后关联。
2. 图片/批量检测成功自动归档；摄像头连续预览按需手动保存。
3. 至少一个检测框且所有框置信度严格大于 0.90 时 AI 自动确认，其余人工复核；无框不自动视为无缺陷。
4. 复核支持确认、改类、改坐标、补框、排除误检，保留原始 AI 结果和修改历史；自动确认有抽检入口。
5. 完成检测和复核后由员工作出钢板质量判定。新增、修正记录使旧判定失效，需重新判定。
6. 草稿报告记录阶段结果；正式报告要求复核与判定完成。保存原图、最终框、参数、类别和权重指纹快照。
7. 按北京时间日期文件夹追溯，搜索和筛选覆盖全部记录。

站内切换保留图片队列，当前请求完成后暂停，返回可继续；刷新/关闭浏览器需要重新选择文件，已归档记录保留。复核编辑有未保存提示与保存后下一张，失败图片可单独重试。
