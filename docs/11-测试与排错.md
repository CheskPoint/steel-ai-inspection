# 测试与排错

backend：.venv/Scripts/python.exe -m unittest discover -s tests -v。
frontend：npm.cmd test、npx.cmd tsc --noEmit、npm.cmd run lint、npm.cmd run test:browser。

浏览器测试自动启动 3001/8001/8002，使用临时数据库、真实模型、合成 MediaStream/MJPEG；需 Chrome、Python 依赖和空闲端口，不访问实体相机。

覆盖认证权限、生产报告闭环、批量停止继续、切页保留、错误恢复、最终框、未保存保护、连续下一张、服务端筛选分页、时区边界、自动/人工统计、指纹快照和窄屏导航。

排错：先看页面错误，/health 检查 HTTP，/system/info 检查模型，核对 Cookie 与主机名，再检查依赖、权重、设备和媒体。401 会话；403 权限/来源；409 重复编号或业务前置条件；422 参数/坐标/日期。
