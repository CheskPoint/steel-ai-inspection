# 数据说明

业务数据在 backend/data，包含业务 SQLite、设备 SQLite、原图/标注图和 camera.key；可通过 STEELVISION_DATA_DIR 配置。先停止后端再整体备份，不遗漏凭据密钥。

保存用户、会话、批次、钢板、检测、复核事件、判定、报告、知识、设置、告警和日志。内部 coils 保留旧名称，界面使用钢板。

检测保存原图尺寸、原始 AI 框、人工最终框、类别表、阈值、指纹和运行条件。历史六类沿用历史表；缺指纹标注未记录，不猜测。报告快照不随后续复核改变。

统计只用归档数据；AI 自动确认与人工复核分开统计，待复核不计入最终分布。摄像头预览帧不归档、不计入生产统计。模型评估与生产统计分开，来源、样本量和条件见 backend/models/evaluation.json。
