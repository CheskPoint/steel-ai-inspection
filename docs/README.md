# SteelVision 开发文档

> 当前开发以 [13-当前阶段说明](13-当前阶段说明.md) 与根目录最新优化方案为准。01—12 为旧版 Mock 原型文档，仅供历史参考。

本文档体系参照 [织慧通 SaaS 项目](https://github.com/supermlk500-del/saas) 的阅读路径和分层方式，并只记录 SteelVision 已实现或明确规划的内容。

## 推荐阅读顺序

1. 想运行项目：阅读 [02-快速启动](02-快速启动.md)。
2. 想理解产品：阅读 [01-项目总览](01-项目总览.md) 和 [04-核心业务流程](04-核心业务流程.md)。
3. 想改页面：阅读 [05-前端开发指南](05-前端开发指南.md)。
4. 想改接口：阅读 [06-后端开发指南](06-后端开发指南.md) 和 [07-接口说明](07-接口说明.md)。
5. 想准备答辩或后续开发：阅读数据、安全、AI、测试和部署章节。
