# 当前能力与验收记录

更新：2026-10-22。当前为 CR7 智检本地业务版本，使用 YOLOv8s 七类模型、CPU、输入尺寸 640。管理员和员工两类账号使用真实 Cookie 会话，生产数据保存在 SQLite 与本地媒体目录。

## 本轮改进

- 检测任务在站内切换后保留图片队列、结果和进度；离开工作台暂停后续处理、释放摄像头。浏览器刷新仍需重新选择未完成的本地文件；已归档结果不丢失。
- 图片支持拖放、文件夹与子目录、状态筛选、停止/继续、仅重试失败项、CSV 导出。默认检测参数修改后同步到空闲工作台，不清空队列。
- 复核卡片按原图叠加最终人工框，保留原始 AI 证据。详情关闭及刷新有未保存保护；可保存后打开下一张匹配记录。末页最后一条移出筛选后自动回到有效页。
- AI 自动确认与人工复核在列表、统计和报告中分别标识。自动确认规则仍为至少一个目标且全部置信度严格大于 90%；不代替人工质量判定。
- 检测与日期文件夹采用服务端筛选分页，每页 36 项；审计日志分页查询，员工接口强制限制本人。首页使用完整汇总，不从当前页推算总量。
- 工作区使用轻量摘要，批量检测结束或暂停后统一刷新；默认旧接口继续返回完整报告，专用详情接口按需读取快照。
- 首页精简待办与入口，布局选择移入设置，手机导航可展开文字菜单。刷新保留所在业务页面与子页，筛选提供清空操作。
- 模型页展示实际类别、运行条件、权重 SHA-256、总体及各类别评估。新归档记录与报告保存模型指纹和运行条件；历史未记录的指纹不补写为当前模型。
- 已同步快速启动、架构、接口、认证、模型、测试和部署文档，移除早期 Mock/假登录等失效说明。

## 模型证据

对实际部署权重执行完整 CR7-DET 验证集评估：402 张图像、1036 个目标，CPU、640、batch=8。

| 指标 | 测量结果 |
| --- | --- |
| Precision | 79.60% |
| Recall | 85.47% |
| mAP@0.5 | 87.21% |
| mAP@0.5:0.95 | 57.40% |
| 单图纯推理平均耗时 | 143.33 ms |

耗时排除预处理、NMS、采集、网络、排队及归档；不是产线帧率。评估文件为 `backend/models/evaluation.json`；本地运行记录在忽略的 `outputs/model-evaluation-20261022/`，可移植脚本为 `scripts/evaluate_model.py`。接口只展示与实际权重指纹一致且字段有效的证据。

## 使用边界

实体 RTSP 设备、厂商认证与编码、USB 实体硬件尚需现场验证；当前摄像头测试使用合成 MediaStream 和真实解码的本地 MJPEG。厂商私有 SDK、光源同步、PLC/MES、现场质量标准与产线精度验收尚未完成。当前没有公网发布。

操作步骤见 [快速启动](02-快速启动.md)。备份应停止后端，完整保留 `backend/data/`（包括 camera.key）。首次初始化账号为 admin/admin123，已有密码不会因重启恢复默认。
