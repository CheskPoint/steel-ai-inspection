# 部署运维

当前交付为本地应用，未发布公网。网页 localhost:3000，后端 localhost:8000，接口文档 localhost:8000/docs，不混用 localhost 与 127.0.0.1。

启动见快速启动。前端 npm.cmd run build，后端需要 Python 与 best.pt；前端无法独立替代推理和业务服务。更换地址要同步配置 NEXT_PUBLIC_API_BASE_URL、STEELVISION_ALLOWED_ORIGINS 和同主机名规则。

备份前停后端，整体复制 backend/data（含 camera.key）。更换模型前备份 best.pt 和 evaluation.json；评估证据与权重指纹不符时指标不可用。

CPU 串行推理的验证批次耗时不等于产线 FPS；采集、排队、网络、NMS、绘图和归档会增加延迟。实体 RTSP、厂商 SDK、PLC/MES 和现场标准需单独验收。Cloudflare 模板保留，未验证线上 GPU 或共享存储部署。
