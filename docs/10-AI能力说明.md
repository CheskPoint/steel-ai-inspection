# 10 AI 能力说明

当前后端通过 Ultralytics 加载真实 YOLO 目标检测权重；模型在首次获取模型信息或推理时加载并缓存。替换权重后需重启后端。

## 当前模型（2026-10-22）

- 权重来源：`E0_CR7_YOLOv8s/weights/best.pt`。
- 部署位置：`backend/models/best.pt`。
- 推理设备：CPU；输入尺寸：640；置信度阈值由界面传入。
- 类别编号 0–6：`inclusion`、`dents`、`oil_spots`、`pits`、`punching`、`linear`、`macular`。
- 后端检查实际权重的任务及类别顺序是否与业务配置一致；不一致时不会继续推理。

## 推理和归档

`backend/app/services/inference.py` 返回实际检测框、置信度、标注图、原始图像尺寸及 `model_classes` 类别表。`bbox` 是原始图片像素坐标 `x1/y1/x2/y2`，不是百分比。

每条新归档记录保存类别表快照。历史六类记录没有 `model_classes` 字段时，继续使用原来的六类编号和名称；原始检测、复核记录、报告不会因模型切换而重写。人工补框和修改类别都按该条记录的类别表执行，不能把旧编号直接套用到新模型。

知识库默认显示当前七类，并保留历史类别入口。相同英文类别键的已有中文名称、描述、图片和备注会保留。

## 验证边界

模型信息见登录后的 `/api/v1/system/info`。`/health` 仅表示 HTTP 服务可响应，不能代替模型加载和真实推理检查。已对当前部署权重完成 CR7-DET 验证集评估：402 张图片、1036 个目标，CPU、输入 640、batch=8。Precision 79.60%，Recall 85.47%，mAP@0.5 87.21%，mAP@0.5:0.95 57.40%。平均单图纯推理 143.33 ms，不含预处理、NMS、采集、网络、排队或归档，不能换算成产线吞吐量承诺。

证据保存在 `backend/models/evaluation.json`；SHA-256 为 `389224c0d2b23c76231bb89dd896747823763910df3ca08d003aba9b3c3c1ebc`。接口校验评估与实际权重指纹一致后才展示。新检测与报告保存指纹、运行条件和类别表；历史缺失字段显示未记录，不回填为当前权重。数据集指标仍需用真实现场数据验证。

仓库提供 `scripts/evaluate_model.py`，验证集图片和 YAML 配置需自行准备，不会上传 GitHub。在仓库根目录执行：

```powershell
backend\.venv\Scripts\python.exe scripts\evaluate_model.py --data "C:\path\to\cr7_det.yaml" --images "C:\path\to\images\val"
```

脚本把新结果写入忽略的 `outputs/model-evaluation/evaluation.json`；核对权重指纹、数据集和条件后，才人工更新部署用的 `backend/models/evaluation.json`。

旧权重和本次切换说明见 `backend/README.md` 的模型切换章节。

## 自动完成与人工复检

至少检测到一个目标，且每个框的置信度均严格超过 90% 时，结果标记为 AI 自动确认，并保存系统事件。任何框置信度不超过 90%，或没有检测框时，仍进入待复检队列。不会把系统自动完成写成人工确认；自动确认结果仍可由人工进一步修正。自动完成不替代钢板最终质量判定。
