# 前端开发指南

在 frontend 执行 npm.cmd install、npm.cmd run dev -- --port 3000。API 默认与网页同主机名的 8000 端口，可通过 NEXT_PUBLIC_API_BASE_URL 配置。

模块：page.tsx 导航；DetectionPanel.tsx 队列和本机摄像头；NetworkCamera.tsx 网络采集；InspectionViews.tsx 分页和复核；BusinessViews.tsx 生产与统计；ReportViews.tsx 报告；ModelView.tsx 评估证据；AuditView.tsx 日志；UserDirectory.tsx 账号；ui.tsx 表单与抽屉。

api.ts 统一 Cookie 请求与错误；useQuery.ts 提供防抖/取消/刷新。成功写入调用 reload，刷新工作空间并通知当前分页查询；批量检测仅暂停或结束时刷新汇总。

图像使用鉴权 img。原图与 SVG 最终框保持相同几何比例，bbox 使用原图像素。

验证：npm.cmd test、npm.cmd run test:browser、npx.cmd tsc --noEmit、npm.cmd run lint。

Worker 运行时声明由 wrangler 生成，重建命令：npx.cmd wrangler types worker-configuration.d.ts --config worker/types.wrangler.jsonc --include-env false。此配置仅生成类型，部署仍使用 vite.config.ts。
