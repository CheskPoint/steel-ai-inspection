# 系统架构

浏览器通过带 Cookie 的 HTTP 请求访问 FastAPI；后端执行身份、权限、图像校验、推理、归档和质量规则。

- page.tsx：导航、汇总、保持检测面板挂载；站内离开暂停采集，保留文件队列。
- useQuery.ts：筛选防抖、取消旧请求、服务端分页与刷新通知。
- routers：认证、业务、推理、设备接口。
- services/queries.py：SQLite 参数化查询、分页和全量统计。
- services/inference.py：懒加载模型、锁保护 CPU 推理、权重指纹和运行条件。
- services/business.py：事务归档、自动确认、判定约束、报告快照。
- services/cameras.py：网络采集进程、状态、超时与释放。
- db.py 与 services/media.py：持久化用户、会话、业务、审计和图像。

新前端使用 /workspace?compact=true，不下载全量检测明细；只返回汇总、生产档案、钢板记录数、最近五条日志及报告概要。检测、日期文件夹和审计按需分页。旧完整工作空间接口保留兼容。

内部 coils 为历史兼容命名，界面统一钢板。网页 localhost:3000，API localhost:8000，必须使用同一主机名。
