# CR7 智检项目总览

更新：2026-10-22。用于冷轧钢板表面缺陷检测与质量追溯，已接入真实本地模型和数据库。

业务闭环：生产批次 → 钢板登记 → 图片或摄像头检测 → AI 自动确认 / 人工复核 → 人工质量判定 → 报告快照 → 日期追溯。

当前 YOLOv8s 模型在 CPU 上运行，输入尺寸 640，识别夹杂、凹痕、油斑、凹坑、冲孔、线状划痕、黄白色斑七类。账号分为总管理员和员工，共享生产数据；管理员管理账号、设备配置、知识和系统配置。

React / TypeScript / Vinext 前端，FastAPI 后端，SQLite 持久化，Ultralytics 推理。数据保存在 backend/data，模型保存在 backend/models。当前为本地应用，未完成真实产线验收、PLC/MES 对接、厂商 SDK 或公网部署。评估证据见 [AI 能力说明](10-AI能力说明.md)。
