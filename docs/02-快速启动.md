# 安装与操作指南

## 1. 启动网站

本机已有模型环境。首次安装才需要创建虚拟环境；更新本次摄像头功能后须安装新增依赖。

在项目 backend 目录：

```powershell
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe -m uvicorn app.main:app --reload --host 127.0.0.1 --port 8000
```

另开终端，在 frontend 目录：

```powershell
npm.cmd install
npm.cmd run dev -- --port 3000
```

打开 http://localhost:3000 ，首次初始化账号为 `admin` / `admin123`。进入系统设置修改密码；修改后不会在重启时恢复默认密码。右上角“模型已加载”来自真实后端检查，首次加载可能稍慢。

已有服务正在运行时，直接刷新网页；不要重复启动相同端口。前端和 API 必须使用同一个主机名。例如网页为 localhost，API 也必须为 localhost。

## 2. 建立生产关联

1. 生产批次 → 新建批次，填写编号、产线和日期。
2. 钢板管理 → 登记钢板，选择所属批次，填写钢种和规格。
3. 点击钢板卡片“去检测”，工作台自动选中该钢板；也可在工作台顶部切换。
4. 暂不关联的试检也会保存，可在质量追溯打开详情后补充关联。

## 3. 图片与文件夹检测

- 单张图片：选择 JPG/PNG → 开始检测。原图、模型结果和检测参数自动归档。
- 文件夹批量：选择文件夹 → 开始图片检测，包含子目录。缩略图可查看单张结果，状态筛选可定位失败项；停止会等待当前图片完成，再停止安排下一张，可继续剩余任务。
- 选择图片支持拖放；仅重试失败项不会重新处理成功项。站内切换会保留队列并暂停后续处理；浏览器刷新后需重新选择未完成文件，已归档记录保留。
- 每张图片最大 10 MB。损坏图片单独报告错误，不中断后续任务；批量明细可导出 CSV。

## 4. 内置 / USB 摄像头

1. 检测工作台 → 实时监测 → 来源选“本机 / USB 摄像头”。
2. 点击“发现 / 刷新摄像头”，允许浏览器使用摄像头。
3. 在“本机设备”中选择摄像头 → 打开摄像头 → 开始连续检测。
4. 停止检测后，点击“保存当前结果”归档右侧已处理画面对应的原始帧。
5. 关闭摄像头或离开工作台会释放设备；设备拔出会停止并提示重新选择。

浏览器必须通过 localhost 或 HTTPS 访问。若显示占用错误，关闭会议软件、系统相机等占用程序。只采集视频，不申请麦克风。

## 5. 网络摄像头（RTSP / HTTP）

1. 设备管理 → 添加网络设备。
2. 填写名称与完整视频流地址，例如 `rtsp://192.168.1.20:554/厂商提供的路径`。HTTP 需填写可解码的视频/MJPEG 流，不是摄像头网页管理地址。
3. 用户名、密码填写在独立字段中 → 启用设备 → 保存配置。
4. 在设备卡片点“测试连接”，看到画面后点击“停止测试并断开”。
5. 检测工作台 → 实时监测 → 来源选“网络摄像头” → 选择设备 → 连接设备 → 开始网络连续检测。
6. 停止后保存当前结果；用完断开设备。离开页面也会请求释放连接。

摄像头和运行后端的电脑需网络互通。准确视频路径、认证方式和编码取决于设备说明。连接/读取超时会显示原因并释放进程；当前只允许一个活动网络视频源。设备密码加密保存在本地，页面与错误信息不返回明文凭据。

已验证本地合成 MJPEG 视频的真实解码和模型推理；尚未获得你的实体摄像头地址，不能据此声称具体 RTSP 设备已接通。需要厂商私有 SDK 的工业相机仍需单独适配。

## 6. 复核、判定与报告

1. 缺陷复核 → 点击图像卡片。
2. 可切换原始 AI 图层；确认结果、全部排除误检，或选择“修正 / 补充缺陷”。
3. 点击“画框补充”后在原图拖动补充漏检区域；也可用加号新增，再调整类别和像素坐标。删除选中框可排除单个误检。
4. 填写复核说明 → 保存复核；可勾选保存后打开下一张匹配记录。未保存修改关闭详情时会提示保存或放弃。原始检测结果保留，每次复核另存记录。
5. 钢板管理 → 质量判定 → 填写结论和依据。没有检测或仍有待复核记录时不能判定。
6. 质检报告 → 选择钢板 → 草稿或正式报告。正式报告必须完成复核及判定。
7. 查看报告 → 打印 / 另存为 PDF，在浏览器打印窗口选择保存为 PDF。

报告保存的是生成时的快照。后续新增检测、修改复核或变更关联会使原钢板结论需要重新判定，但已生成的报告不被覆盖。

## 7. 其他页面

- 质量追溯：按图片、日期（北京时间）、批次、钢板、缺陷类型和复核状态查找，详情查看时间线。
- 质量分析：归档图片量、待复核数量、已确认缺陷分布和每日归档量。预览帧不重复累计为生产数据。
- 缺陷知识库：七个真实模型类别，支持编辑说明和上传示例图；未上传时显示明确标注的形态示意。
- 用户与权限：管理员管理用户和配置；员工执行检测、复核、判定等业务。不能停用或降级最后一个管理员。
- 告警中心：处理设备连接失败、检测异常和不合格钢板告警，记录处理说明。
- 操作日志：管理员按账号、动作、日期和内容分页查询。
- 界面设置：顶部入口或系统设置中切换角色工作台 / 原版布局；手机菜单可展开文字导航。
- 筛选无结果时可以一键清空筛选。
- 系统设置：默认置信度、帧间隔、报告标题、单位名称和个人密码。保存的检测默认值会同步到工作台；执行中的任务完成或暂停后生效。

## 8. 保存与备份

业务数据库、图片、设备配置和加密密钥在 `backend/data/`。刷新网页或重启服务不会丢失业务数据。先停止后端，再完整备份目录；恢复时将整个目录放回，不要只复制设备数据库而遗漏 camera.key。

测试服务器使用独立临时目录，不会把测试钢板写入日常数据。更多接口与环境变量见 backend/README.md。

## 9. 常见问题

- 模型未连接：检查后端 8000 端口和本地权重，点击右上角状态重试。
- 登录后又要求登录：检查前后端是否混用 localhost 和 127.0.0.1。
- 403 来源错误：使用默认本机地址；自定义端口需设置后端 `STEELVISION_ALLOWED_ORIGINS`，前端 `NEXT_PUBLIC_API_BASE_URL` 修改后需重启。
- 摄像头有预览但检测速度慢：当前 CPU 串行推理；帧间隔是额外等待时间，不能保证固定帧率。
- 结果归档失败：查看后端日志和磁盘空间，错误记录会在可写入数据库时进入告警中心。
- 质量判定被拒绝：先为钢板关联至少一张检测图像并完成全部复核。
