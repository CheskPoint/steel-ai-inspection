# 认证权限与安全

已使用真实账号、密码哈希与服务端会话，非 SessionStorage 模拟登录。admin/admin123 仅首次初始化建立。

会话为随机令牌，库内保存 SHA-256；Cookie 为 HttpOnly、SameSite=Lax，HTTPS 下设置 Secure，有效期 12 小时。密码带随机盐哈希保存，只能重设不能查看。

角色为总管理员 admin 和员工 inspector；生产数据团队共享，管理配置由管理员维护。员工日志接口仅本人。当前员工没有日志和系统设置导航，界面设置只管理个人布局。

角色变化、停用、管理员重设密码撤销目标会话；修改本人密码撤销其他会话。至少保留一名启用管理员。

写请求验证 Origin 白名单和同主机名，CORS 限定来源并允许凭据。图片限制格式与 10 MB、实际解码；媒体需登录。摄像头凭据加密、错误地址脱敏。

当前本地运行，未声称公网安全验收、企业 SSO、登录限流或按产线/员工独立数据隔离。
