# 管理员与员工工作台

本次调整按两类账号实现：总管理员、员工。原来的实施员工与只读员工合并，不再提供独立的只读角色。

## 页面与对比

登录页提供「员工登录」和「管理员登录」两个身份按钮，共用账号密码表单。默认选中员工登录；如果账号与入口不匹配，会提示选择正确的入口，不建立新会话。账号实际权限由服务端保存的角色决定。

登录后，通过顶部「界面设置」或系统设置中的布局控件，可以在「角色工作台」和「原版布局」之间切换。选择按账号保存在当前浏览器，下次访问会记住；不影响其他账号。

- 角色工作台：管理员先看到团队账号、待复核数量、告警、全员最近操作；员工先看到检测入口、团队待办、本人权限和本人最近操作。管理员导航优先展示组织管理，员工导航优先展示质检工作。
- 原版布局：保留原来的总览和导航顺序，便于比较。用户管理、日志隔离等实际权限在两种布局中一致；这不是恢复旧版本权限的开关。
- 两种布局的侧栏都使用图标，不再使用序号。

## 两类权限

| 能力 | 总管理员 | 员工 |
| --- | --- | --- |
| 查看生产业务、检测结果、质量分析、报告 | 可以 | 可以 |
| 检测、采集、归档、批次与钢板登记及更新 | 可以 | 可以 |
| 缺陷复核、质量判定、生成报告、处理告警 | 可以 | 可以 |
| 使用已配置的摄像头 | 可以 | 可以 |
| 配置设备、修改知识库与系统配置 | 可以 | 不可以 |
| 创建账号、修改角色、停用账号、重设密码 | 可以 | 不可以 |
| 操作日志 | 全员分页查询 | 无独立导航入口；接口限制为本人 |
| 修改本人密码 | 可以 | 可以 |

「员工不能修改」落实为不能修改账号权限和管理配置；员工仍可以保存日常工作结果。生产数据是团队共享数据，尚未按员工分配独立的批次或钢板。

## 管理账号

管理员进入「用户与权限」，可按姓名或登录账号搜索、筛选角色和状态。每个成员提供「编辑权限」和「查看操作」；页面下方有完整权限对照表。

账号密码只可重设，不可查看原密码。修改角色、停用账号或重设密码会使该账号已有登录会话失效，员工需要重新登录。系统禁止停用或降级最后一个启用的总管理员。管理员修改自己的角色、状态或密码时，会返回登录页。

「操作日志」支持按员工、操作类型、日期和内容筛选，分页加载记录。权限变更记录包含目标账号、变更前后的角色/状态/显示名称以及是否重设密码，不保存密码内容。日志记录已实现的关键业务与账号操作，不记录每次鼠标点击或页面浏览。

## 旧账号兼容

后端启动时会将历史 `viewer` 账号转为 `inspector`（员工），保留账号 ID、用户名、密码、启用状态与已有业务记录。迁移会撤销这些账号的旧会话，并写入一条系统操作日志。重复启动不会重复迁移或重复写日志。新建账号默认是员工，接口只接受 `admin` 和 `inspector`。

更新代码后请重启后端，刷新前端页面。如果之前用的是带 `--reload` 的后端，保存代码后会自动重新加载。测试使用临时数据库，不向日常数据库添加演示员工。
