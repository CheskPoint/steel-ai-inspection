# 接口说明

更新：2026-10-22。实际字段及校验以 FastAPI `/docs`、`backend/app/routers/` 为准。业务前缀 `/api/v1`，前端请求携带 Cookie；修改请求校验 Origin。除健康检查与登录外，业务接口需要有效会话。

## 查询

| 方法与路径 | 用途 |
| --- | --- |
| GET `/health` | HTTP 服务存活检查，不等于模型就绪 |
| GET `/system/info` | 实际模型、类别、SHA-256、运行条件、经指纹校验的评估 |
| GET `/workspace?compact=true` | 首页摘要、生产数据、设置、报告摘要、最新 5 条可见日志；不加载全部检测记录 |
| GET `/workspace` | 兼容旧客户端的完整工作区，包括完整报告快照 |
| GET `/inspections` | 检测分页与筛选，返回 `{items,total}` |
| GET `/inspection-folders` | 北京时间日期分组，返回 `{items:[{date,total,pending}],total}` |
| GET `/inspections/{id}` | 原始结果、最终复核结果及该记录事件 |
| GET `/analytics` | 全量汇总、自动与人工分别计数、类别及日期统计 |
| GET `/audit-logs` | 服务端审计分页；员工无论参数如何只能读取本人记录 |
| GET `/reports/{id}` | 完整不可变报告快照 |
| GET `/media/{filename}` | 经鉴权的业务图片 |

检测及文件夹筛选参数为 `query,batch,coil,status,category,from,to,folder,offset,limit`。日期格式 YYYY-MM-DD，以北京时间解释；offset 默认 0，limit 默认 36、最大 500。coil=unassigned（兼容 unlinked）查询未关联记录。status 支持 pending、auto_confirmed、human_reviewed、completed、confirmed、corrected、false_positive；类别按最终复核框匹配。total 是全部匹配项数量。

`/analytics` 接受 from/to。`/audit-logs` 接受 query/actor/action/day/offset/limit，返回 items/total/actions。`compact=true` 的 inspections 为空；统计必须读取 stats、inspection_counts 或专用查询接口，不能从摘要数组推算总数。

## 检测

POST `/inferences` 使用 multipart/form-data：file 为 JPG/JPEG/PNG，最大 10 MB；threshold 范围 0.1–0.95、默认 0.25；source 为 manual/batch/camera；coil_id 可选；archive 可选，图片默认归档、摄像头默认仅预览。浏览器自动生成 multipart boundary。

响应包含 model、model_classes、model_sha256、runtime、count、detections、image_width、image_height、annotated_image，以及归档后的 record_id/review_status。每个检测框包含 class_id、class_name、confidence 和 bbox，bbox 是原图像素数组 `[x1,y1,x2,y2]`，不是百分比。未归档的 record_id 为 null。批量顺序调用同一接口，失败由用户手动重试。

## 修改

| 方法与路径 | 用途 |
| --- | --- |
| POST `/auth/login`、`/auth/logout`、`/auth/password` | 登录、退出、修改本人密码 |
| POST `/batches`、`/coils`；PATCH 对应 `/{id}` | 登记和更新生产关联 |
| PATCH `/inspections/{id}` | 更新钢板关联 |
| POST `/inspections/{id}/review` | 保存 status/note/detections，保留原始 AI 结果与历史事件 |
| POST `/coils/{id}/judgment` | 完整性校验后的质量判定 |
| POST `/reports` | 生成草稿或正式报告快照 |
| PATCH `/settings`、`/knowledge/{key}` | 管理员配置 |
| POST `/users`；PATCH `/users/{id}` | 管理员账号管理 |
| PATCH `/alerts/{id}` | 告警处理 |

设备接口由 `routers/devices.py` 定义，包含设备管理、连接、预览、检测、保存与断开。设备凭据不以明文返回。

错误以 HTTP 状态和 detail 表达：401 未登录、403 权限或来源限制、404 不存在、409 业务冲突、413 文件过大、415 类型不支持、422 参数无效、503 推理暂不可用。图片解码失败返回 400。前端显示可读原因，不自动重放有副作用的请求。
